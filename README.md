### For developers

The site is in [`site/`](site/): Vite + React + TypeScript + Tailwind v4, using Motion, GSAP ScrollTrigger and Lenis.

```bash
cd site
npm install
npm run dev
```

Every push to `main` rebuilds and redeploys the preview through GitHub Actions (`.github/workflows/deploy.yml`).
